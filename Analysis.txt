When there is no optimization the function starts eith the label LFB0 while with optimization it starts with LFB13. Labeling in general is slightly different between O1 and O3. While O1 does use L1, O3 does not use L1. O0 uses the least about of registers while O3 uses the most going as far as using 12d while O0 only goes up to edi. The increased number of registers used allows the O3 code to run the fastest.
